# 文档智能系统 · Electron 桌面版

基于大语言模型的**文档理解**与**多源数据融合**一体化桌面应用。本目录为可独立开发、打包的 Electron 发行版（前端 + 本地 API + 业务代码 `src/`）。

---

## 项目背景与目标

企业日常办公中积累了大量**非结构化文本**（合同、经营报告、客户反馈、技术资料等），格式不一、来源分散。传统人工阅读、摘录、录入效率低、易出错。

本系统以大语言模型（LLM）为核心，面向办公场景实现：

- 对多源异构文档的**自动理解、抽取与结构化**；
- 将非结构化信息转化为可关联、可分析的数据资产；
- 支撑**自动填表、智能问答、知识整理、跨文档检索**等应用。

程序可部署于**桌面端**（亦可扩展 Web / 服务端），通过本地 API 与前端协作完成文档处理任务。

## 功能模块与使用提示词

系统包含**六大对话模式**和**工作流画布**两大交互入口，以下分别说明。

---

### 1. 默认对话（default_conversation）

**适用场景：** 无需文档，直接与 AI 进行自由问答、头脑风暴、文案生成等通用对话。

**使用方式：** 在对话框直接输入文字，无需上传文件，模式选择「默认对话」即可。

**示例提示词：**

```
帮我写一封请假邮件，请假时间是下周一到周三，原因是身体不适。
```

```
用 Python 实现一个快速排序算法，要求支持泛型和自定义比较函数。
```

```
把下面这段话改得更正式一些：我们明天下午开会，讨论一下新版本的功能。
```

---

### 2. 文档理解（document_understanding）

**适用场景：** 上传任意格式文档（PDF、Word、TXT、Markdown、Excel 等），让 AI 读取并基于文档内容回答问题。

**支持格式：** `.pdf` `.docx` `.txt` `.md` `.xlsx` `.xls`

**使用方式：**

1. 在附件区点击「+」选择本地文件，或从文档库勾选文件
2. 模式切换为「文档理解」
3. 输入问题发送

**示例提示词：**

```
这份会议纪要的核心结论是什么？列出 3-5 条要点。
```

```
根据这份合同，甲方需要在什么时间之前完成什么义务？
```

```
帮我把这篇文档总结成 200 字以内的摘要。
```

```
这份报告里提到了哪些财务数据？帮我整理成表格。
```

### 4. 实体提取（entity_extraction）

**适用场景：** 从非结构化文档（PDF、Word、TXT、Markdown）中自动抽取结构化字段，输出为 JSON，可配合 Excel 模板填表。

**支持格式：** `.pdf` `.docx` `.txt` `.md`

**使用方式：**

1. 上传文档到数据文件区
2. （可选）上传 Excel 模板作为输出格式参考
3. 模式切换为「实体提取」
4. 描述要提取的字段

**示例提示词：**

```
从这份合同中提取：甲方名称、乙方名称、合同金额、签署日期、合同期限。
```

```
提取文档中所有人员信息：姓名、职务、电话、邮箱。
```

```
从会议纪要中提取：会议主题、参会人员、决议事项、待办任务。
```

```
提取这篇新闻的：标题、发布时间、来源、关键人物、核心事件。
```

---

### 5. 表格填表（table_filling）

**适用场景：** 有一个数据源 Excel 和一个输出模板（Word 或 Excel），让 AI 根据数据源内容自动填写模板。

**支持格式：**

- 数据源：`.xlsx`
- 模板：`.xlsx` 或 `.docx`

**使用方式：**

1. 上传 Excel 数据源到「数据文件」区
2. 上传模板到「模板文件」区
3. 模式切换为「表格填表」（也可由系统自动识别）
4. 描述填表要求

**示例提示词：**

```
根据数据源中的客户信息，填写合同模板。
```

```
把数据源里每个部门的年度数据填入汇总表模板。
```

```
将源数据中的产品信息填入报价单模板，价格列保留两位小数。
```

---

### 6. 提取填表 / 混合模式（mixed）

**适用场景：** 同时上传了文档文件和 Excel 模板，系统自动先从文档提取结构化信息，再将结果填入模板，完成「非结构化 → 结构化 → 模板填充」的完整链路。

**典型工作流程：**

```
文档（PDF/Word/TXT/MD）
   ↓ 实体提取（Agent B）
结构化 JSON 数据
   ↓ 表格填表（Agent C）
填好的 Excel / Word 模板
```

**支持格式：**

- 文档源：`.pdf` `.docx` `.txt` `.md`
- 数据源（可选）：`.xlsx`（已有结构化数据时可直接作为数据源）
- 输出模板：`.xlsx` 或 `.docx`

**使用方式：**

1. 上传文档文件到「数据文件」区（可多份）
2. 上传 Excel/Word 模板到「模板文件」区
3. 系统自动识别为混合模式，也可手动切换
4. 描述需要提取的字段和填表要求

---

**场景一：合同批量填表**

```
从这几份合同中提取：甲方名称、乙方名称、合同金额、签署日期、合同期限，然后填入汇总表模板。
```

**场景二：招聘简历汇总**

```
把这几份简历里的姓名、学历、工作年限、期望薪资提取出来，填入招聘汇总模板。
```

**场景三：会议纪要整理成表**

```
从这几份会议纪要中提取：会议日期、主题、参会人员、决议事项，填入会议跟踪表。
```

**场景四：客户信息整理**

```
从这些客户反馈文档中提取客户名称、联系方式、反馈类型、问题描述，填入客户服务台账。
```

**场景五：发票/报销信息提取**

```
从这几份发票照片识别内容中提取：发票号码、开票日期、金额、销方名称，填入报销明细表。
```

**场景六：多文档多模板联合处理**

```
从 PDF 合同提取甲方和金额，从 Word 补充协议提取附加条款，分别填入对应的 Excel 模板。
```

> **提示：** 如果数据源本身已经是 Excel（结构化数据），只需上传数据源 Excel + 输出模板，系统会跳过提取步骤直接进行填表（即「表格填表」模式）。只有上传了非结构化文档（PDF/Word/TXT/MD）时，系统才会先执行提取再填表。

## 工作流画布

工作流支持将多个处理节点串联，适合批量、可复用的文档处理流程。

### 内置节点类型

| 节点         | 说明                              | 示例用途             |
| ------------ | --------------------------------- | -------------------- |
| **文档输入** | 选择文档作为流程起点              | 上传待处理文件       |
| **AI 翻译**  | 全文翻译，支持指定目标语言        | 合同翻译、资料本地化 |
| **内容提取** | 生成摘要 / 提取要点 / 两者兼有    | 会议纪要要点提炼     |
| **实体抽取** | 按字段从文档抽取结构化数据        | 合同信息批量提取     |
| **文本增强** | 语法检查 / 润色 / 改写 / 全面优化 | 公文润色、邮件改写   |
| **密码脱敏** | 自动识别并掩码敏感信息            | 身份证、手机号脱敏   |
| **文档输出** | 保存流程结果为文件                | 导出最终产物         |

### 工作流示例提示词（节点内 AI 节点的 prompt）

**翻译节点：**

```
请将以下文档全文翻译为英文，保持 Markdown/段落结构，仅输出译文。
```

**内容提取节点：**

```
请对以下文档生成一段 200 字以内的摘要，并列出 5 条关键要点。
```

**文本增强节点：**

```
请检查以下文本的语法错误，润色表达，使其更正式、专业。
```

**实体抽取节点：**

```
从文档中提取：人名、机构名、日期、金额、地址。
```

**密码脱敏节点：**

```
识别文档中的身份证号、手机号、银行卡号，替换为 **** 形式的掩码，其余内容保持不变。
```

## 快速开始

### 环境要求

- Windows 10/11（x64）
- Node.js 18+、npm
- Python 3.11+（仅开发或未打包 API 时需要）
- 可访问的 LLM API（在应用「API 与模型设置」中配置）

### 开发运行

```powershell
cd desktop-electron
.\scripts\run_dev.ps1
```

或：`.\scripts\run_dev.cmd`

### 打包

```powershell
cd desktop-electron
.\scripts\build.ps1
```

或：`npm run build`（自包含三步：前端 → API 内嵌 dist → Electron）。

产物：

- 安装包：`dist-electron\文档智能系统 Setup <版本>.exe`
- 免安装：`dist-electron\win-unpacked\文档智能系统.exe`

## 模型配置

1. 启动应用 → **API 与模型设置**
2. 下拉选择供应商（DeepSeek / 智谱 / OpenAI 兼容等）
3. 填写 API Key、模型名、Base URL（若需要）

配置文件路径：

```
%APPDATA%\document-intelligence-desktop-electron\data\settings.json
```

未配置或 Key 无效时，依赖 LLM 的功能将无法使用。
